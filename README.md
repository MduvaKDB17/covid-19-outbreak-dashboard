
# COVID-19 Early Outbreak Dashboard

## Project Overview

The COVID-19 Early Outbreak Dashboard is a web-based application designed to visualise and analyse COVID-19 outbreak statistics between February and March 2020.

The dashboard aims to provide an interactive and user-friendly interface for exploring historical COVID-19 data across selected countries.

## Project Objectives

- Visualise confirmed cases, deaths and recoveries.
- Calculate and display active COVID-19 cases.
- Analyse outbreak trends across selected countries.
- Provide interactive charts and country-based filtering.
- Develop a responsive and user-friendly dashboard.

## Countries Covered

- China
- Italy
- South Korea
- United States
- South Africa

## Technologies

- HTML5 - Web page structure
- CSS3 - Styling and responsive design
- JavaScript - Application logic and interactivity
- JSON - Data storage
- Chart.js - Data visualisation (planned)
- Git and GitHub - Version control

## Data Source

The supplied COVID-19 dataset is based on the Johns Hopkins CSSE COVID-19 Data Repository.

The initial project structure, HTML foundation, country selector and dashboard metric containers have been created.
